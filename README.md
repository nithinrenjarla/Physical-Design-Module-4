# Physical-Design-Module-4
# Timing Analysis, Clock Tree Synthesis &amp; Physical Design

# Project Overview
This project explores the physical design and timing-analysis phases of the RTL-to-GDSII implementation flow using the PicoRV32A processor design, OpenLane, OpenROAD, and the SKY130A technology library.
The module covers the complete implementation sequence:
RTL Design → Logic Synthesis → Technology Mapping → Floorplanning → Placement → Clock Tree Synthesis → Timing Analysis → Routing → Physical Verification
The project also focuses on key concepts related to digital circuit timing, including:
- Setup Time

- Hold Time

- Data Arrival Time

- Data Required Time

- Slack

- Clock Skew

- Clock Latency
  
- Clock-Tree Buffering
  
- Interconnect and Crosstalk-Induced Delay

- Ideal-Clock Timing

- Propagated/Real-Clock Timing

#  Objectives

 The major objectives of this project are:
 
1.To gain practical knowledge of the RTL-to-GDSII physical-design flow.

2.To configure and run the OpenLane automated physical-design flow.

3.To implement and evaluate the PicoRV32A design using the SKY130A PDK.

4.To understand the process of logic synthesis and technology mapping.

5.To examine the standard-cell count and different cell types produced during synthesis.

6.To study floorplanning and placement and observe the physical distribution of cells.

7.To understand the purpose and operation of Clock Tree Synthesis (CTS).

8.To analyse clock buffering and clock-network distribution.

9.To examine clock skew and clock latency in the implemented design.

10.To understand setup and hold timing constraints and their analysis.

11.To study the impact of interconnect resistance and capacitance (RC) delays on timing.

12.To examine the influence of crosstalk on delay and clock skew.

13.To interpret and analyse timing reports generated by OpenROAD.

14.To differentiate between ideal-clock analysis and propagated-clock analysis.

15.To understand the process of timing closure and techniques used to improve slack.
