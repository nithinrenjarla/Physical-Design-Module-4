# Physical-Design-Module-4
# Timing Analysis, Clock Tree Synthesis &amp; Physical Design

# Project Overview
This project explores the physical design and timing-analysis phases of the RTL-to-GDSII implementation flow using the PicoRV32A processor design, OpenLane, OpenROAD, and the SKY130A technology library.
The module covers the complete implementation sequence:
RTL Design → Logic Synthesis → Technology Mapping → Floorplanning → Placement → Clock Tree Synthesis → Timing Analysis → Routing → Physical Verification
The project also focuses on key concepts related to digital circuit timing, including:
- Setup Time

- Hold Time

- Data Arrival Time

- Data Required Time

- Slack

- Clock Skew

- Clock Latency
- Clock-Tree Buffering
Interconnect and Crosstalk-Induced Delay
Ideal-Clock Timing
Propagated/Real-Clock Timing
🎯 Objectives
The major objectives of this project are:
To gain practical knowledge of the RTL-to-GDSII physical-design flow.
To configure and run the OpenLane automated physical-design flow.
To implement and evaluate the PicoRV32A design using the SKY130A PDK.
To understand the process of logic synthesis and technology mapping.
To examine the standard-cell count and different cell types produced during synthesis.
To study floorplanning and placement and observe the physical distribution of cells.
To understand the purpose and operation of Clock Tree Synthesis (CTS).
To analyse clock buffering and clock-network distribution.
To examine clock skew and clock latency in the implemented design.
To understand setup and hold timing constraints and their analysis.
To study the impact of interconnect resistance and capacitance (RC) delays on timing.
To examine the influence of crosstalk on delay and clock skew.
To interpret and analyse timing reports generated by OpenROAD.
To differentiate between ideal-clock analysis and propagated-clock analysis.
To understand the process of timing closure and techniques used to improve slack.
